# 依存パッケージの固定状況

- 初期版のPythonは3.13以上。ローカルの検証ではPython3.13.5。
- `application/pyproject.toml` は公式 `mcp==2.3.0` を明示。ただし配布物の検査値と推移的な依存を固定したロックファイルはまだ存在しない。
- ネットワークが許されるクリーンなPython3.13仮想環境で依存を解決し、すべてのパッケージのバージョンとSHA-256検査値を含むロックファイルを生成・検証するまで `task.scope.015` は `blocked`。
- その状態での公式MCP通信試験は実行していない。`pip freeze` の結果だけでは完全固定と呼ばない。
- Rust、Lean、Kaniのツールチェーンは任意段階で採用する際に別途固定する。
