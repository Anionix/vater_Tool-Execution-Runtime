# Security policy

**Experimental only. Not production-approved.**

- Do not run against untrusted remote clients or with privileged API credentials.
- Real MCP interoperability, full authentication, external reconciliation, and long-duration fault testing have not been certified.
- Never include access tokens, passwords, personal data, private logs, or credentials in public issues.
- For security-sensitive findings, avoid posting exploit details or secrets publicly until a responsible private reporting route is configured.
- The project does not currently promise response or patch deadlines.
